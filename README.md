# Shortform Engine

Demo: https://shortform-engine-iota.vercel.app

Zero-touch 9:16 factory. Paste a script or JSON file, press Render, and Remotion plays a finished short of 30–60 seconds. The template is a field in the script. Nobody scrubs a timeline to finish the edit.

An original four-second bed loops under the captions. The picture is faceless kinetic type.

## Free replacements

| Paid tool | Replacement |
| --- | --- |
| ElevenLabs | `speechSynthesis` in the browser. Captions are timed by the script, not by a paid alignment API |
| Premiere / Canva templates | Remotion compositions: Hook, List, Story, chosen in the script |
| Licensed music | `public/bed.wav`, generated by `scripts/make-bed.mjs` |

## Run

```bash
npm install
npm run bed
npm run verify
npm run dev
```

Nothing is uploaded. Rendering stays in the player, so the page can be hosted as a normal Next.js app.
