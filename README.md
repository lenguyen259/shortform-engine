# Shortform Engine

Programmatic 9:16 shorts. Edit three lines, pick a template, and Remotion plays the cut in the browser. An original four-second bed loops under the captions.

## Free replacements

| Paid tool | Replacement |
| --- | --- |
| ElevenLabs | `speechSynthesis` in the browser. Captions are timed by the script, not by a paid alignment API |
| Premiere / Canva templates | Remotion compositions: Hook, List, Story |
| Licensed music | `public/bed.wav`, generated by `scripts/make-bed.mjs` |

## Run

```bash
npm install
npm run bed
npm run verify
npm run dev
```

Nothing is uploaded. Rendering stays in the player, so the page can be hosted as a normal Next.js app.
